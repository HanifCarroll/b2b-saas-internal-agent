# Switchboard review UI

Next.js with shadcn components. See the root README for API startup and demo identity details.

```sh
npm ci
npm run dev -- --hostname 127.0.0.1
```

Open http://localhost:3000. Enter a saved proposal ID and its scenario run ID. The API must be running on 127.0.0.1:8000.

```sh
npm run lint
npm run build
```
